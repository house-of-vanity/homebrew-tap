# homebrew-tap

Personal Homebrew tap for custom formulas.

## Installation

```bash
brew tap house-of-vanity/tap
brew install rexec
```

## Available Formulas

- **rexec** - Remote execution tool

## Direct installation

```bash
brew install house-of-vanity/tap/rexec
```

## Repository structure

```
homebrew-tap/
├── Formula/
│   └── rexec.rb
└── README.md
```
